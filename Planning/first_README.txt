INSTRUCTIONS ON HOW TO INSTALL AND RUN THE WINDOWS VERSION OF TURBOFEM
----------------------------------------------------------------------
1) At first you need to have already some python.exe from any version on your computer and run "main_TurboFEM_versions.py" in the correct folder using internet only for the first time, or download all packages of argos from:
	https://1drv.ms/f/c/77d97863382bfb2f/IgDQZar9cf0xRptpPgZaUAtPAcwpS15iXzUOt-TBamHVNKQ

2) Run "builder_of_TurboFEM_exe.py" or "main_TurboFEM_versions.ps1" in the folder of ".\TurboFEM_exe" without changing the rest of the file's tree 

3) Optionally, install TurboFEM.exe in another download's link.
   You can download it from:
       https://1drv.ms/f/c/77d97863382bfb2f/IgCxiVU0FncdTquf0fAIDuVcAf_h8wDMMzS9oSwJUs-Mvvw

   It is strongly recommended to install these in directories with no white spaces.

4) Run "main_TurboFEM_versions.py" in the correct folder or just run TurboFEM.exe

5) From the TurboFEM's interface, you can now put all data from your selected mechanical model and after all you can also see all results and download them or download your mechanical model for another FEM's application such as Abaqus for example.


NOTES

1) You can also use TurboFEM in others languages if you go to %LocalAppData% in windows an do
